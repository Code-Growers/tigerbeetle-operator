The TigerBeetle operator is installed in namespace {{ .Release.Namespace }}.

1. Check that it is running:

   kubectl -n {{ .Release.Namespace }} rollout status deployment/{{ include "tigerbeetle-operator.fullname" . }}

2. Create a TigerBeetle cluster. The cluster ID, replica count and storage size cannot be changed
   later; read https://github.com/Code-Growers/tigerbeetle-operator/blob/main/docs/deploying.md first.

   kubectl apply -f - <<EOF
   apiVersion: tigerbeetle.codegrowers.com/v1alpha1
   kind: TigerBeetleCluster
   metadata:
     name: my-tigerbeetle
   spec:
     # A random 128-bit integer, e.g. from: python3 -c 'import secrets; print(secrets.randbits(128))'
     clusterID: "<random u128>"
     replicas: 3
     storage:
       size: 10Gi
     resources:
       requests:
         cpu: "1"
       limits:
         memory: 8Gi   # 5GiB of it becomes TigerBeetle's grid cache
   EOF

3. Watch it come up, then point clients at the published addresses:

   kubectl get tigerbeetlecluster my-tigerbeetle -w
   kubectl get configmap my-tigerbeetle-config -o yaml
